# Mundo Peluche

Juego 3D de peluches en el navegador, con mundo abierto, coches, mar y multijugador por salas.

**Jugar:** https://rogergc222004.github.io/Mundo-Peluche/

## Multijugador
1. Abre **Multijugador**, pon tu apodo y tu color.
2. Uno toca **Crear sala** y comparte el código de 6 letras.
3. Los demás escriben ese código y tocan **Entrar**.

Las salas se conectan directo entre jugadores (WebRTC con PeerJS). Quien entra primero hace de anfitrión;
si se sale, otro jugador toma su lugar automáticamente.
